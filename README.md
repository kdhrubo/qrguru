# QR Code Generator and URL Shortener API

## Description

This project is a Spring Boot application that provides functionalities for:
1.  **QR Code Generation**: Dynamically generates QR code images based on provided data.
2.  **URL Shortening**: Creates short aliases for long URLs and redirects users to the original URL when the short alias is accessed.

The application uses an in-memory H2 database for storing URL mappings in the URL shortener feature.

## Prerequisites

*   **Java JDK**: Version 17 or newer.
*   **Apache Maven**: Version 3.6.x or newer.

## How to Build and Run

1.  **Clone the repository:**
    ```bash
    git clone <your-repository-url-here>
    cd qrcode-generator
    ```
    (Replace `<your-repository-url-here>` with the actual URL of the repository)

2.  **Build the project:**
    This command compiles the code, runs tests, and packages the application into a runnable JAR file in the `target/` directory.
    ```bash
    mvn clean package
    ```

3.  **Run the application:**
    Once the build is successful, you can run the application using the following command:
    ```bash
    java -jar target/qrcode-generator-0.0.1-SNAPSHOT.jar
    ```
    The application will start, and by default, it will be accessible at `http://localhost:8080`.

## Available API Endpoints

### QR Code Generation

*   **Endpoint:** `GET /api/qrcode/generate`
*   **Description:** Generates a QR code image in PNG format.
*   **Request Parameters:**
    *   `data` (String, required): The text or data to be encoded in the QR code.
    *   `width` (int, optional, default: 250): The width of the QR code image in pixels.
    *   `height` (int, optional, default: 250): The height of the QR code image in pixels.
*   **Example Usage (curl):**
    ```bash
    curl -o qrcode.png "http://localhost:8080/api/qrcode/generate?data=Hello+Spring+Boot&width=300&height=300"
    ```

### URL Shortener

#### Shorten URL

*   **Endpoint:** `POST /api/shorten`
*   **Description:** Creates a short alias for a given long URL.
*   **Request Body (JSON):**
    ```json
    {
            "url": "your_long_url_here"
    }
    ```
*   **Example Usage (curl):**
    ```bash
        curl -X POST -H "Content-Type: application/json" -d '{"url":"https://spring.io/projects/spring-boot"}' http://localhost:8080/api/shorten
    ```
*   **Example Response (JSON):**
    ```json
    {
        "originalUrl": "https://spring.io/projects/spring-boot",
        "shortCode": "aBcDeFg", 
            "fullShortenedUrl": "http://localhost:8080/aBcDeFg" 
    }
    ```
    (Note: `shortCode` and `fullShortenedUrl` will be dynamically generated.)

#### Redirect Short Code

*   **Endpoint:** `GET /{shortCode}`
*   **Description:** Redirects to the original URL associated with the provided `shortCode`.
*   **Example Usage (browser or curl):**
    Open in browser: `http://localhost:8080/aBcDeFg`
    (Replace `aBcDeFg` with an actual short code generated by the `/api/shorten` endpoint)
    
    Using curl (to follow redirect):
    ```bash
    curl -L http://localhost:8080/aBcDeFg
    ```

## How to Run Tests

To execute the unit tests for the application, run the following Maven command:
```bash
mvn test
```

This command will compile the test classes and run all tests found in the `src/test/java` directory. Test results will be displayed in the console.
